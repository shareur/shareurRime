## 一、主题与皮肤

### macOS（鼠须管）

配置在 `squirrel.custom.yaml`：

| 项 | 当前值 | 说明 |
| --- | --- | --- |
| `color_scheme` | `solarized_light` | 亮色主题 |
| `color_scheme_dark` | `solarized_dark` | 暗色主题，**跟随系统深色模式自动切换** |
| `candidate_list_layout` | `linear` | 所有皮肤的候选一律横向排列 |

`squirrel.yaml` 内置了多套 `preset_color_schemes`（含社区皮肤，作者信息保留在各皮肤条目的 `author` 字段）；
`squirrel.custom.yaml` 另外新增了 `roseo_maple`、`calm` 两套。

### Windows（小狼毫）

配置在 `weasel.custom.yaml`：当前使用 `WhiteAqua` 皮肤，并包含 `MacRoseo` / `MacRoseoAlt` 两套自定义皮肤，
`style` 里控制了字体（`Microsoft Yahei`）、字号、横向排列、候选间距等。

### 字体（含回退）

`squirrel.custom.yaml` 的 `font_face` 支持**逗号分隔的回退列表**，从前到后取系统里第一个存在的字体：

```yaml
font_face: "MesloLGMDZ Nerd Font Propo, Source Han Serif SC VF, Source Han Serif SC"
font_point: 20                       # 候选字号
label_font_point: 16                 # 序号字号
comment_font_point: 17               # 编码提示字号
```

- 首选等宽 Nerd Font（带图标字形），次选思源宋体，都没有则用系统默认；
- 修改字号/字体后需重新部署。

## 二、自定义短语与个人词库

| 文件 | 作用 | 生效方式 |
| --- | --- | --- |
| `custom_phrase.txt` | 全局自定义短语（`rime_ice` 的 `table_translator@custom_phrase` 读取） | 重新部署 |
| `user_dicts/01_custom.dict.yaml` | 个人自定义英文词汇（如 ChatGPT、GitHub） | 重新部署 |
| `user_dicts/02_en_names.dict.yaml` | 英文人名词库 | 重新部署 |
| `wubi86_jidian_user.dict.yaml` | 极点五笔的个人词库 | 重新部署 |

词条格式为 `候选词<Tab>输入码`（必须是 Tab，不是空格）：

```
ChatGPT	chatgpt
GitHub	github
```

> 词频习惯、用户词典（`*.userdb/`）由 Rime 自动维护，**不要手工编辑、也不要提交到仓库**（它们是个人数据，见 [06-常见问题](06-常见问题.md)）。

## 三、按应用自动切英文

`squirrel.custom.yaml` 的 `app_options` 可指定某些程序启动时直接进入英文（ASCII）模式：

```yaml
  app_options:
    com.termius-dmg.mac:
      ascii_mode: true
```

需要别的程序时，把自己的 bundle id 按同样格式加进去即可（注释里已有 Chrome / Safari / MWeb 的示例）。
