# 小鹤音形（flypy）配置说明

[← 返回文档索引](README.md) · [← 返回 README](../README.md) · [← 方案总览](02-各输入方案说明.md)

本仓库的主力方案之一。本文说明 **小鹤音形 10.26.11**（`flypy`）在本仓库中的配置：码表组成与启用状态、
三种词库模式、符号与快符、OK 拼字、反查，以及升级与排错。

- 本仓库的 `flypy.schema.yaml` 以该包为基线，仅保留 3 处本地改动（见第八节）

## 二、码表组成与当前启用状态

小鹤音形在 Rime 中由「主码表 + 若干辅库」组成：

| Rime 文件 | 加载方式 | 当前状态 | 说明 |
| --- | --- | --- | --- |
| `build/flypy.table.bin`（预编译） | `translator.dictionary: flypy` | ✅ 启用 | 主码表（首选字词）。官方只发预编译，无源码 |
| `flypy_sys.txt`（8,484 条） | `custom_phraseXT` | ✅ 启用 | 系统辅库：符号编码（O 符 / 成组符号 / 快符）、二简次选、emoji、部分字词 |
| `flypy_top.txt`（2 条） | `custom_phraseVD` | ✅ 启用 | 置顶词库：与系统词重码时**居前** |
| `flypy_user.txt`（0 条） | `custom_phraseYH` | ✅ 启用 | 用户词库：与系统词重码时**居后** |
| `flypyok.dict.yaml`（88,020 条） | `ok_mode.dictionary` | ✅ 启用 | OK 拼字码表（表外字拼字），**本地补全** |
| `flypydz.dict.yaml`（9,548 条） | `reverse_lookup.dictionary` | ✅ 启用 | 反查单字码表（万能键、复制反查） |
| `flypy.dict.yaml` | 不随仓库分发 | — | 主码表**源码**，官方不提供；本仓库不收录（`.gitignore` 已忽略），`flypy.table.bin` 由官方预编译件提供 |
| `flypy_full全码字.txt`（2,158 条） | `custom_phraseQMZ` | ❌ 未启用 | 全码字分类，**文件名须改为 `flypy_full.txt` 才生效**（见第三节） |

> 当前处于**熟手模式**：`flypy_top/user` 不含全码词，`flypy_full` 未激活。

## 三、词库模式：熟手 / 常规 / 初学

官方把词库分三个递进阶段（对词库「做减法」）：

| 模式 | 全码词 | 全码字 | 适合人群 |
| --- | --- | --- | --- |
| **初学** | 启用 | 启用 | 学习单字/词的全码拆分 |
| **常规** | 启用 | 关闭 | 实际使用阶段，单字有简打简 |
| **熟手**（当前） | 关闭 | 关闭 | 已熟悉高频二简词 |

### 如何切换

**→ 切到「常规」**（启用全码词）
1. 打开 `others/模式切换&补充简码方案.txt`（官方附带，本仓库已收录）
2. 把「全码词 置顶」清单粘到 `flypy_top.txt` 末尾；或把「全码词 居后」清单粘到 `flypy_user.txt` 末尾
3. 重新部署

**→ 切到「初学」**（常规 + 启用全码字）
1. 先按上面步骤启用全码词
2. 把 `flypy_full全码字.txt` 改名为 `flypy_full.txt`
3. 重新部署

**→ 回到「熟手」**
- 清空 `flypy_top.txt` / `flypy_user.txt` 里的全码词条目
- 把 `flypy_full.txt` 改回 `flypy_full全码字.txt`（或删掉）
- 重新部署

> 清单以官方 `模式切换&补充简码方案.txt` 为准，其中还有「二简次选」清单（`bw` → 1.被 2.背 这类），
> 需要时把条目粘到 `flypy_sys.txt`。

## 四、符号编码（O 符 / 成组符号 / 快符）

符号都走 `o` 前缀，收录在 `flypy_sys.txt`，与官网帮助页一致：

| 类型 | 编码 | 输出 |
| --- | --- | --- |
| 最简 O 符 | `oq` `ow` `oi` `oa` `od` `of` … | ‰ _ 😊 & 、 → … |
| 圆圈数字 | `oyy` `oye` `oys` `oyf` `oyw` … | ① ② ③ ④ ⑤ … |
| 特殊符号 | `ota` `otd` `otk` `otz` … | ＆α、°＝≠、⤴␣∅、↑↓← |
| 拼音字母 | `opa` `opo` `ope` `opi` `opu` `opv` … | ā á、ō ó、ē é ê、ī í、ū ú、ǖ ǘ ü … |
| 成组符号 | `ofyu` `ofku` `ofbd` `ofux` `ofpy` … | ①②③…、⑴⑵…、标点组、数学符号、拼音字母组 |
| 快符 | `;q` `;y` `;u` `;t` | ：“ 《 》 ^ |

> `ok` 前缀留给 OK 拼字，不再作符号码（旧版 `ok`→《 已移除，改由 `;y`→《）。
> 完整符号表见 <https://flypy.cc/help/#/fh>。


## 五、OK 拼字（表外字输入）

输入 `ok` + 二分双拼码，可拼出《通用规范汉字表》外的字（支持 GB 18030-2022）：

```
okhguu     → 丁      okhgve     → 七
okhgppve   → 万      okhohoho   → 焱（三分）
```

实现方式：

| 配置 | 作用 |
| --- | --- |
| `affix_segmentor@ok_mode` | 识别 `ok` 前缀并剥离 |
| `table_translator@ok_mode`（`dictionary: flypyok`） | 用剥离后的码查 `flypyok` 码表 |
| `recognizer.patterns.ok_mode: "^ok[a-z']*$"` | 把 `ok` 开头的输入标记为拼字模式 |
| `schema/dependencies: flypyok` | 触发 `flypyok` 码表编译 |

- `flypyok.dict.yaml` 共 88,020 条，由**旧版**官方包附带的 `flypy_ok.txt` 生成（编码去掉开头 `ok`）。
- ⚠️ 官方 10.26.11 包**不再附带** `flypy_ok.txt`，也没有提供 `ok_mode` 配置；本仓库保留了该功能，
  因此这份码表沿用旧版数据，官方若后续改版需重新生成。

## 六、日期 / 时间 / 计算器

| 功能 | 编码 | 输出 |
| --- | --- | --- |
| 当前日期 | `orq` | 2026年08月28日 / 2026-08-28 |
| 当前时间 | `ouj` | 14:30 |
| 计算器 | `=1+2*3` | 7（`lua/calculator_translator.lua`） |
| 重复最近上屏 | `;f` | 上一次上屏内容（`history`） |

> 日期/时间编码由旧版 `date`/`time` 改为 `orq`/`ouj`，实现在 `rime.lua`，与官网直通码一致。

## 七、反查与万能键

- **万能键 `` ` ``**（Tab 上方）替代任一码位反查编码：
  - 不知道读音：用 `` ` `` 代替双拼两码 + 双形两码
  - 不知道形码：双拼两码 + `` ` `` 代替双形两码
- **复制反查**：`ofi` 查询剪贴板文字的编码
- 数据来自 `flypydz.dict.yaml`（通规 + 表外 + 生僻字，9,548 条）

## 八、键位与本地差异

### 常用组合键（官方 key_binder）

| 组合键 | 功能 |
| --- | --- |
| `Ctrl+.` | 切换中/英标点 |
| `Shift+空格` | 切换全/半角 |
| `Ctrl+j` | 简繁转换 |
| `Ctrl+m` | 切换到下一个方案 |
| `Ctrl+反引号` / `F4` | 呼出方案选单 |
| `;` | 次选上屏（`semicolon → 2`） |
| `$` / `\|` | 输入中替代次选（要打出 `$` / `\|` 本身，用 `Release+$` / `Release+\|`，分别输出句号、逗号） |
| `,` / `.` | 顶屏（标点直出） |
| `[` / `]` | 上/下翻页 |
| `Tab` / `Caps_Lock` / `Shift_R` | 取消当前输入 |
| 反引号 | 万能键反查 |

> 想启用「分号引导快符」（`;q` 直接出符号而不是次选），需要把 `key_binder/bindings` 里的
> `{accept: semicolon, send: 2, when: has_menu}` 注释掉，并自行加上
> `{accept: Release+semicolon, send: semicolon, when: has_menu}`。启用后分号将失去「次选」功能。

### 与官方包的 3 处差异

| 位置 | 官方 10.26.11 | 本仓库 | 原因 |
| --- | --- | --- | --- |
| `ok_mode` + `flypyok` | 无 | 有 | 补回官方未提供的 OK 拼字 |
| `speller/auto_select_pattern` | `^;.$\|^\w{4}$`（4 码也自动上屏） | `^;.$` | 连打时 4 码自动上屏会让再按空格多出一个空格 |
| `simplification/opencc_config` | `s2hk.json`（香港繁体） | `s2tw.json`（台湾正体） | 个人习惯的繁体字形 |

其余（`speller`、`translator`、`reverse_lookup`、`custom_phrase*`、`key_binder`、`recognizer`、`menu`、`style`）
与官方 10.26.11 一致；`schema/version` 也保持官方的 `10.26.11`。

## 九、升级与部署

### 主码表怎么升级

1. 从 [flypy.cc](https://flypy.cc/) 下载最新的「Rime 平台 · 鼠须管」挂接包，放到 `others/flypy/`（本地目录，不随仓库跟踪）
2. 覆盖主码表与辅库：

   ```bash
   cd ~/.local/share/fcitx5/rime            # macOS 为 ~/Library/Rime
   unzip -o "others/flypy/小鹤音形“鼠须管”for macOS.zip" -d /tmp/flypy-pkg
   P=/tmp/flypy-pkg/小鹤音形Rime平台鼠须管for\ macOS/rime
   cp "$P"/build/flypy.table.bin "$P"/build/flypy.prism.bin "$P"/build/flypy.reverse.bin build/
   cp "$P"/flypy_sys.txt "$P"/"flypy_full全码字.txt" "$P"/flypydz.dict.yaml .
   ```

3. 对照官方 `flypy.schema.yaml` 与本地版本，把官方新配置合并进来（保留第八节列出的 3 处差异）
4. 重新部署

### 部署日志里的一条「错误」（正常现象）

```
E ... dict_compiler.cc:86]  source file '.../flypy.dict.yaml' does not exist.
E ... dict_compiler.cc:115] neither flypy.dict.yaml nor flypy.table.bin exists.
```

官方不提供主码表 `.dict.yaml`，Rime 想重编译时找不到源文件就会报这条。
**只要 `build/flypy.table.bin` 存在，`flypy` 就正常工作**，可以忽略。

> 若你自己在本地保留了从码表反推的 `flypy.dict.yaml`（可检索的字表），部署时 Rime 会用它
> 重编 `build/flypy.*.bin`（schema 变动会触发字典重建）。只要该 dict 与官方码表同源，
> 重编结果与官方文件**同尺寸、仅差校验和**，属预期行为；想恢复成官方原始二进制，
> 用挂接包的 `build/` 覆盖即可。换新挂接包时按「先覆盖 bin、再更新 dict」的顺序保持一致。

### 其他注意事项

- **主码表无源码**：不要指望仓库里有 `flypy.dict.yaml`；本机若从旧备份恢复了它，`.gitignore` 已忽略，**请勿提交**
- 存在该源码时重新部署会用它重编 `build/flypy.*.bin`；要恢复官方版本，用挂接包的 `build/` 覆盖回去
- 所有修改（增词条、切模式、改名 `flypy_full.txt`）都要重新部署才生效
- 升级前版本可从 git 历史回滚：`git checkout <提交> -- flypy.schema.yaml`
