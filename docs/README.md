## 文档规范

1. **README 只放门面**：一句话定位、特性、方案表、快速开始、文档索引、许可；不再堆细节。
2. **单一主题单一文件**：新增问题先想清楚属于哪一类，新建或追加到对应文档，避免在 README 里堆长段落。
3. **文件名用编号前缀**（`NN-中文标题.md`），保证目录里的阅读顺序稳定；文件名不要带括号等需转义的字符。
4. **每篇文档头部带返回链接**，内部交叉引用使用相对路径（`02-各输入方案说明.md`）。
5. **命令与路径写完整**，涉及平台差异时用表格分列 macOS / Windows / Linux。
6. 修改文档后同步更新本索引与 [`CHANGELOG.md`](../CHANGELOG.md)。
