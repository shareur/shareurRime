## 三、小鹤音形（`flypy`）的特别说明

1. **方案与码表版权属于原作者何海峰**（[flypy.cc](https://flypy.cc/)）。本仓库只是把官方「Rime 挂载包」接入到自己的配置中，**不对其方案、码表主张任何权利**。
2. 官方发布包**只提供预编译码表**（`build/flypy.table.bin` / `flypy.prism.bin` / `flypy.reverse.bin`），不提供 `flypy.dict.yaml` 等源码文件。
   解开官方「鼠须管 for macOS」挂接包可见，其中只有 `build/*.bin`、`flypy_sys.txt`、`flypy_top.txt`、`flypy_user.txt`、
   `flypy_full全码字.txt`、`flypydz.dict.yaml`、`flypy.schema.yaml`、`rime.lua` 与说明文档，**没有主码表 `.dict.yaml`**。因此：
   - 本仓库**不收录 `flypy.dict.yaml`**，并在 `.gitignore` 中显式忽略（本地若存在该文件，属个人从旧备份恢复，请勿提交）；
   - 三个预编译 `build/*.bin` 因无源码无法重建，**必须随仓库保留**，否则 `flypy` 方案失效。
3. 升级主码表请使用官方挂接包中的 `build/` 文件覆盖（步骤见 [03-小鹤音形配置说明](03-小鹤音形配置说明.md) 第九节）。
4. **如需商业使用或二次分发小鹤音形相关内容，请先联系原作者获得授权。**
