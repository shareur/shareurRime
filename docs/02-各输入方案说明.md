# 各输入方案说明

[← 返回文档索引](README.md) · [← 返回 README](../README.md)

本文档列出本 Rime 仓库中**实际启用**的输入方案（以 `default.custom.yaml` 的 `schema_list` 为准），以及每个方案的配置要点。
日常主力是 **小鹤音形 `flypy`** 与 **小鹤双拼 `double_pinyin_flypy`**，其余方案作为补充与兜底。

## 各方案说明

### flypy（小鹤音形）
最复杂的方案，详见 **[03-小鹤音形配置说明](03-小鹤音形配置说明.md)**。要点：
- 主码表为官方预编译 `build/flypy.table.bin`（无源码）
- 辅库：`flypy_sys.txt`（符号/快符）、`flypy_top.txt`（置顶）、`flypy_user.txt`（用户词）、`flypyok.dict.yaml`（OK 拼字）、`flypydz.dict.yaml`（反查）
- 当前为**熟手模式**：全码词/全码字未启用
- 符号：`o` 前缀（`oyy`→①、`oq`→‰、`ofyu`→①…）；日期 `orq`、时间 `ouj`
- 万能键 `` ` `` 反查

### xhup_express / xhup_fluency（小鶴音形·連打 / 語句流）
旧版小鹤音形的连打/语句流方案，同样使用 `flypy` 主码表。`xhup_express` 单字连打、`xhup_fluency` 语句流整句输入。
> 已逐渐被 `flypy`（音形）取代，若不需要可在 `default.custom.yaml` 的 `schema_list` 中删除。

### double_pinyin_flypy（小鹤双拼）
纯小鹤双拼方案，挂载雾凇词库 `rime_ice.dict.yaml`。开关：`ascii_mode`、`ascii_punct`（中英标点）、`traditionalization`（简繁）、`emoji`、`full_shape`、`search_single_char`（辅码查词单字优先）。

### rime_ice（雾凇拼音）
全拼方案（雨凇/雾凇词库，6 个词典：`base`/`ext`/`others`/`tencent`/`8105`/`41448` 等，见 `rime_ice.dict.yaml`）。开关与 `double_pinyin_flypy` 相同。作为默认全拼使用。

### pinyin_simp（简体拼音）
独立全拼方案，词库 `pinyin_simp.dict.yaml`。简单轻量，不依赖雾凇词库。

### wubi86_jidian 系列（极点五笔）
- `wubi86_jidian`：极点五笔 86 主方案，词库 `wubi86_jidian.dict.yaml`（含 `wubi86_jidian_extra`、`_extra_district` 等扩展）
- `wubi86_jidian_pinyin`：五笔 + 拼音混输（打不出时直接打拼音）
- `wubi86_jidian_trad`：简入繁出（简体码表出繁体）
- `wubi86_jidian_trad_pinyin`：繁体拼音混输

### wubi_pinyin / wubi_trad（五笔 86）
经典五笔 86（词库 `wubi86.dict.yaml`）的拼音混输 / 簡入繁出变体。

### numbers（大写数字）
快捷输入大写数字/金额（`numbers.schema.yaml`）。

### melt_eng / easy_en（英文）
- `melt_eng`：Easy English Nano，少量常用词，方便中英混输方案调用
- `easy_en`：Easy Stream English，25 万词 + 人名 + 自定义词库（`easy_en.dict.yaml` + `user_dicts/`）

`easy_en` 的 Lua 增强位于 `lua/easy_en.lua`，挂载方式见 `easy_en.custom.yaml` / `easy_en.schema.yaml`：

| 组件 | 作用 |
| --- | --- |
| `lua_filter@*easy_en*enhance_filter` | 追加整句 / 生词候选（📝）并写入用户词典；带 ☯ 的候选额外给出 💡 整句拆分结果 |
| `lua_processor@*easy_en*enter_no_space` | 回车选词上屏时去掉候选尾部空格（空格选词逻辑不变） |

整句拆分依赖可选的 wordninja，四种方式在 `easy_en.schema.yaml` 的 `easy_en:` 节点选择：`split_sentence`（总开关）、`use_wordninja_rs_lua_module` + `wordninja_rs_lua_module_path`（Lua 模块）、`use_wordninja_rs` + `wordninja_rs_path`（命令行）、`use_wordninja_py`（Python 包）。
**若本机没有任何一种 wordninja，脚本会自动降级为「不拆分」**（`wordninja_split` 直接返回原句），`easy_en` 仍可正常使用。

### radical_pinyin（部件拆字）
部件拆字反查方案（词库 `radical_pinyin.dict.yaml`），用于不认识的字按部件/部首反查拼音或编码。

同时，`lua/search.lua`（`lua_filter@*search@radical_pinyin`）为 `rime_ice` 与 `double_pinyin_*` 系列提供 **反引号辅码查词**（用部件拆字过滤候选）：

- 引导符：`key_binder/search`（当前为反引号，需同时在 `speller/alphabet` 里包含该符号）
- 开关：`search_single_char`（辅码查词时单字是否优先）
- 匹配方式：过滤器命名为 `*search@radical_pinyin`，即用 `radical_pinyin` 方案做 schema 匹配（`if_schema_lookup`）；若在 `search/db` 下配置了反查库则走 reverse 查询（`if_reverse_lookup`，更快）
- 其他可调项：`search/show_other_cands`（是否显示不符合辅码的候选）、`search/tags`（生效的 segment tag）、`search/schema_search_limit`

## 如何增删方案

方案列表由 `default.custom.yaml` 的 `schema_list` 决定，改完都要**重新部署**。

### 停用某个方案

把对应那行删掉（或注释掉）即可，文件继续留在目录里不碍事：

```yaml
patch:
  schema_list:
    - {schema: flypy}
    - {schema: rime_ice}
    # - {schema: xhup_express}   # ← 注释即停用
```

### 启用 `others/optional/` 里的可选方案

以微软双拼为例：

```bash
cd ~/.local/share/fcitx5/rime        # macOS 为 ~/Library/Rime，Windows 为 %APPDATA%\Rime
cp others/optional/double_pinyin_mspy.schema.yaml .          # 1. 复制方案文件到根目录
cp others/optional/en_dicts/cn_en_mspy.txt en_dicts/         # 2. 复制该方案的中英混输词库（纯五笔/t9 跳过）
```

3. 在 `default.custom.yaml` 的 `schema_list` 里加一行 `- {schema: double_pinyin_mspy}`
4. 重新部署，按 `` Ctrl+` `` / `F4` 即可选到

> 复制出来的文件已被 `.gitignore` 忽略，所以「启用」不会让 `git status` 变脏，也不会让同一方案被跟踪两份。
> 另外：双拼方案共用雾凇词库 `rime_ice.dict.yaml`，无需额外复制。

### 新增自己的方案

把 `xxx.schema.yaml`（及所需词库）放到 Rime 用户目录根，在 `schema_list` 里加 `- {schema: xxx}`，
词库里用到的 `import_tables`、`dictionary`、`user_dict` 都要能在同目录找到，然后重新部署。

## 通用说明

- 全局开关（简繁、标点、全半角、emoji 等）由 `default.yaml` / `default.custom.yaml` 定义
- 皮肤/字体在 `squirrel.custom.yaml`（macOS）与 `weasel.custom.yaml`（Windows）中调整
- 修改任意配置后，需在输入法菜单点击「重新部署」生效
- 未启用的 7 个可选方案（自然码 / 微软 / 紫光 / 拼音加加 / 智能 ABC 双拼、纯五笔86、九宫格 t9）
  以「原文件 + 启用说明」的形式收在 [`others/optional/`](../others/optional/README.md)，**已纳入仓库跟踪**，
  开箱即用也够用，需要时再按上面的步骤启用
