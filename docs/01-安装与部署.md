# 安装与部署

[← 返回文档索引](README.md) · [← 返回 README](../README.md)

## 一、支持的前端

本仓库是**纯配置仓库**，不含任何前端程序，可被下列 Rime 前端直接使用（clone 后重新部署即可，开箱即用）：

| 平台 | 前端 | 说明 |
| --- | --- | --- |
| macOS | 鼠须管 Squirrel | 读取 `squirrel.yaml` / `squirrel.custom.yaml` 皮肤配置 |
| Windows | 小狼毫 Weasel | 读取 `weasel.yaml` / `weasel.custom.yaml` 皮肤配置 |
| Linux | fcitx5-rime | 使用 `default.yaml` 与各方案配置，无额外皮肤文件 |
| Linux | ibus-rime | 同上 |
| iOS / Android | 仓输入法 Hamster、iRime 等 | 可参考 `others/` 下的移动端配置示例（该目录不随仓库跟踪） |

> 配置在 librime 1.13 / Weasel 0.17.4 环境下验证（见 `default.custom.yaml` 的 `customization` 段）。

## 二、安装

### 方式 A：git clone（推荐，便于更新）

先把目标目录准备好（见下表），再 clone 或复制进去：

```bash
# macOS（鼠须管）
git clone https://github.com/shareur/shareurRime.git ~/Library/Rime

# Linux（fcitx5-rime）
git clone https://github.com/shareur/shareurRime.git ~/.local/share/fcitx5/rime
```

若该目录**已有内容**（例如前端已生成过默认配置），建议先备份，再用 `git init` + `git remote add` 的方式接管现有目录，避免覆盖个人词频数据库。

### 方式 B：下载 ZIP

从 GitHub 页面「Code → Download ZIP」下载解压后，把文件复制进 Rime 用户目录。

macOS 上也可以用仓库自带的 `macOS-双击复制文件内容.command`：双击运行，脚本会把当前文件夹内容复制到 `~/Library/Rime`，**并先把原有目录备份到桌面**。

### 各平台的 Rime 用户目录

| 平台 / 前端 | 用户目录 |
| --- | --- |
| macOS 鼠须管 | `~/Library/Rime` |
| Windows 小狼毫 | `%APPDATA%\Rime` |
| Linux fcitx5-rime | `~/.local/share/fcitx5/rime` |
| Linux ibus-rime | `~/.config/ibus/rime` |

> 注意：`~/.config/rime` 是部分工具/旧版前端的默认路径，**fcitx5-rime 实际使用** `~/.local/share/fcitx5/rime`。

## 三、重新部署

配置改动（含首次安装）后必须让 Rime 重新编译词库，否则不生效：

| 前端 | 操作 |
| --- | --- |
| 鼠须管（macOS） | 菜单栏输入法图标 → **重新部署** |
| 小狼毫（Windows） | 右键托盘图标 → **重新部署** |
| fcitx5-rime（Linux） | 托盘图标 → **部署**（Deploy） |
| ibus-rime（Linux） | 面板菜单 → **Deploy** |

- 首次部署会编译 `cn_dicts/` 全部词库（含腾讯词向量，约 17 MB），**耗时几分钟属正常**；后续仅重新编译改动过的方案。
- 部署完成后用 `` Ctrl+` ``（或 `F4`）呼出方案菜单选择输入方案。

## 四、仓库不含什么

以下文件属于**运行时产物或个人数据**，不在仓库内，重新部署后会自动重建：

| 文件 / 目录 | 说明 |
| --- | --- |
| `build/` | 编译产物；**例外**：`build/flypy.table.bin` / `flypy.prism.bin` / `flypy.reverse.bin` 必须保留（小鹤音形主码表无源码，删除后 `flypy` 方案不可用） |
| `*.userdb/`、`*.db.txt` | 个人词频与用户词典数据库 |
| `sync/` | Rime 同步备份 |
| `installation.yaml`、`user.yaml` | 本机安装信息（含设备 ID） |
| `flypy.dict.yaml` | 小鹤音形主码表源码（官方不提供，本仓库不收录，见 [07](07-第三方组件与许可.md)） |

判断标准：会被 Rime 重新生成、或属于个人使用记录的文件，都不放入版本库。

## 五、目录结构

```
├── *.schema.yaml            # 输入方案
├── *.dict.yaml              # 词库（含 import_tables 的合成词库）
├── flypy*.txt               # 小鹤音形辅库（sys / top / user / full）
├── build/                   # 编译产物（仅 flypy 三个 bin 入库）
├── cn_dicts/                # 中文词库（雾凇拼音）
├── en_dicts/                # 英文词库（en / en_ext / cn_en*）
├── user_dicts/              # 个人词库（自定义英文词、人名）
├── lua/                     # Lua 扩展（29 个脚本）
├── opencc/                  # Emoji 等 OpenCC 配置
├── docs/                    # 文档（本目录）
├── default.yaml             # 全局默认配置
├── default.custom.yaml      # 全局定制（快捷键、标点、schema_list）
├── squirrel.yaml / .custom  # macOS 鼠须管皮肤
├── weasel.yaml / .custom    # Windows 小狼毫皮肤
├── symbols_v.yaml           # 全拼 v 模式符号表
├── symbols_caps_v.yaml      # 双拼 V 模式符号表
├── custom_phrase.txt        # 自定义短语
└── others/                  # 附加素材（仅以下已入库）
    ├── optional/            # 7 个默认未启用的可选方案 + 启用说明
    └── 模式切换&补充简码方案.txt  # 小鹤官方模式切换清单
```

## 六、更新与卸载

### 更新

```bash
cd <Rime 用户目录>
git pull            # 或先 git stash 保存本地改动
# 然后在输入法菜单里「重新部署」
```

> `git pull` 后如果方案表现异常，删除 `build/` 下对应方案的 `*.bin`（**不要删 flypy 的三个 bin**）再重新部署，可强制重编译。

### 回滚

```bash
git log --oneline            # 找到目标提交
git checkout <commit> -- .   # 或 git reset --hard <commit>（会丢本地改动）
```

### 卸载

把 Rime 用户目录整体备份后删除或改名即可；输入法前端本身的卸载请使用系统包管理器 / 安装包卸载程序。

## 七、平台专属文件

删除以下文件不会影响其他平台，但会丢失对应平台的皮肤/工具：

| 文件 | 仅对 | 作用 |
| --- | --- | --- |
| `squirrel.yaml`、`squirrel.custom.yaml` | macOS | 皮肤、字体、亮暗主题、按应用切英文 |
| `weasel.yaml`、`weasel.custom.yaml` | Windows | 皮肤、字体、候选项布局 |
| `macOS-双击复制文件内容.command` | macOS | 一键安装辅助脚本：双击后把当前文件夹内容复制到 `~/Library/Rime`（会先把原目录备份到桌面） |
