# 常见问题（FAQ）

[← 返回文档索引](README.md) · [← 返回 README](../README.md)

## 部署与安装

**Q1：改了配置没生效？**
必须让 Rime 重新编译：鼠须管菜单 / 小狼毫托盘 / fcitx5 托盘 → **重新部署（Deploy）**。
只重启输入法不会重新编译词库。

**Q2：部署很慢，卡在词库上？**
首次部署要编译 `cn_dicts/` 全量词库（含腾讯词向量约 17 MB），几分钟正常。后续只重编改动过的方案。
想加快可临时把 `rime_ice.dict.yaml` 里 `cn_dicts/tencent` 一行注释掉（候选量会变少）。

**Q3：我的 Rime 目录不是 `~/.config/rime`？**
fcitx5-rime 使用 `~/.local/share/fcitx5/rime`，ibus-rime 使用 `~/.config/ibus/rime`，
macOS 是 `~/Library/Rime`，Windows 是 `%APPDATA%\Rime`。见 [01-安装与部署](01-安装与部署.md)。

**Q4：方案菜单是空的 / 找不到小鹤音形？**
检查 `default.custom.yaml` 的 `schema_list` 是否包含目标方案，且对应 `*.schema.yaml` 文件存在；
`flypy` 还需要 `build/flypy.table.bin` 等三个预编译码表未被删除。

**Q4b：想用微软双拼 / 紫光双拼 / 纯五笔86 / 九宫格 t9？**
它们默认未启用，但文件已随仓库提供，放在 `others/optional/`：

```bash
cp others/optional/double_pinyin_mspy.schema.yaml .      # 方案文件复制到根目录
cp others/optional/en_dicts/cn_en_mspy.txt en_dicts/    # 该方案的中英混输词库
# 然后在 default.custom.yaml 的 schema_list 加一行 - {schema: double_pinyin_mspy}，重新部署
```

详见 [02-各输入方案说明](02-各输入方案说明.md#启用-othersoptional-里的可选方案) 与
[`others/optional/README.md`](../others/optional/README.md)。

## 小鹤音形

**Q5：`flypy` 打字没候选 / 部署报缺码表？**
`build/flypy.table.bin` / `flypy.prism.bin` / `flypy.reverse.bin` 被删了。
这三个文件是官方预编译主码表（无源码），必须保留，从仓库或官方挂接包恢复后重新部署。

**Q5b：部署日志里有 `source file 'flypy.dict.yaml' does not exist`，是出错了吗？**
不是。官方不提供主码表 `.dict.yaml` 源码，Rime 尝试重编译时找不到源文件就会打这条日志；
只要 `build/flypy.table.bin` 在，`flypy` 就正常工作，可以忽略。详见
[03-小鹤音形配置说明](03-小鹤音形配置说明.md#部署日志里的一条错误正常现象)。

**Q6：为什么仓库里没有 `flypy.dict.yaml`？**
官方挂接包只提供预编译码表，不含 dict 源码；本仓库因此不收录该文件（已在 `.gitignore` 中显式忽略）。
详见 [07-第三方组件与许可](07-第三方组件与许可.md)。

**Q7：想从「熟手」切到「常规 / 初学」模式？**
见 [03-小鹤音形配置说明](03-小鹤音形配置说明.md) 第三节：把官方「模式切换&补充简码方案.txt」里的
全码词清单粘到 `flypy_top.txt` / `flypy_user.txt`，初学模式再把 `flypy_full全码字.txt` 改名为 `flypy_full.txt`。

**Q8：分号不是快符，而是"选第二个候选"？**
当前 `flypy.schema.yaml` 里 `{accept: semicolon, send: 2, when: has_menu}` 生效，
切换说明见 [03-小鹤音形配置说明](03-小鹤音形配置说明.md#八常用组合键)。

**Q9：`ok` 开头的编码打不出字？**
`ok` 前缀保留给 OK 拼字（`flypyok` 码表），符号请用 `o` 前缀（`oyy`→①、`oq`→‰…），快符用 `;` 前缀。

## 英文输入

**Q10：英文整句没有被拆分（没有 💡 候选）？**
缺少可选依赖 wordninja，脚本会自动降级为不拆分（属正常行为）。安装方式与三个开关见
[04-英文输入说明](04-英文输入说明.md)。

**Q11：按回车选英文会多一个空格？**
`lua/easy_en.lua` 的 `enter_no_space` 处理器专门去掉 Enter 上屏时候选尾部的空格；
若仍出现，确认 `easy_en.custom.yaml` 里挂了 `lua_processor@*easy_en*enter_no_space`。

## 编码与快捷键

**Q12：辅码/反查怎么用？**
- 万能用 `<反引号>`（Tab 上方）替代任一码位反查编码（`flypy`，数据来自 `flypydz.dict.yaml`）；
- `rime_ice` / `double_pinyin_*` 用反引号引导部件拆字辅码（`lua/search.lua` + `radical_pinyin` 方案），
  开关 `search_single_char` 控制"单字是否优先"；
- `radical_pinyin` 方案本身可按部件/部首拆字输入。

**Q13：中英标点、简繁、全半角怎么切？**
`Ctrl+.` 中英标点、`Ctrl+j`（或 `Ctrl+反引号` 菜单）简繁、`Shift+空格` 全半角；
更多见 `default.custom.yaml` 的 `key_binder`。

## 仓库相关

**Q14：仓库里都有什么？`others/` 是干什么的？**
跟踪的是一份「换机器 / 换平台后仍然需要」的配置：16 个已启用方案 + 词库 + 皮肤 + 文档，
以及 `others/optional/`（7 个默认未启用的可选方案）与 `others/模式切换&补充简码方案.txt`。
其余文件（`build/` 编译产物、`sync/` 同步备份、`*.userdb/` 词频库、`installation.yaml` 等）属于
运行时数据或个人记录，不进版本库。

**Q15：能直接 `git clean -xfd` 清理吗？**
**不能**。会把 `sync/`、`*.userdb/` 以及你自己放进来的其它未跟踪文件一起删掉。

**Q16：`sync/`、`installation.yaml`、`*.userdb/` 是什么？**
Rime 的同步备份、本机安装信息（含设备 ID）、个人词频数据库 —— 都是个人数据，**不要提交**。

**Q17：如何更新到最新配置？**
`git pull` → 重新部署；异常时删掉 `build/` 下对应方案的 `*.bin`（**不要删 flypy 三个 bin**）强制重编译。
